Privacy Policy — YouTube Autopilot

Last updated: 26 October 2026.

YouTube Autopilot is a private tool used only by the owner of the NeuroPRO YouTube channels to upload, schedule and describe his own videos.

What data the tool uses

With the owner's consent, the tool uses the YouTube Data API to upload videos, set titles, descriptions, thumbnails and publication time, and read basic statistics of the owner's own channels.

How the data is stored

The access token is stored only on the owner's private server. The tool does not collect data about other people, does not sell or share data with third parties, and does not use it for advertising.

Google API Services

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. YouTube API Services are used under the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
